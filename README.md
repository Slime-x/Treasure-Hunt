# Treasure-Hunt
This is a game about trying to find a diamond buried somewhere underground.

# How to play
### Controls
Use A and D to move, SPACE to jump, left click on a tile to dig it up and right click to let it go.
When you dig up a tile, you can go to the platform at spawn, let the tile go and deposit it like that and repeat tha until you get to the diamond.
